# Sprint_7 — Автотесты для API Яндекс.Самокат

## Описание

Проект автоматизирует тестирование API учебного сервиса Яндекс.Самокат.  
Тесты реализованы на Java 11 с использованием JUnit 4, RestAssured и Allure для отчётности.

Покрытие:
- ✅ Создание курьера
- ✅ Логин курьера
- ✅ Создание заказа (параметризованный тест)
- ✅ Получение списка заказов

---

## Технологии

- Java 11
- Maven
- JUnit 4
- RestAssured
- Jackson
- Allure (JUnit4 + RestAssured)
